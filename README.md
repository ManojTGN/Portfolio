# ManojTGN's Portfolio

> Writes code. Breaks code. Fixes code. (Usually in that order.)

A clean, fast, and highly interactive personal portfolio built with **Next.js 15** and **Tailwind CSS**. This project showcases my work, skills, and experience with a focus on responsiveness, accessibility, and internationalization.

## ✨ Features

- **Responsive Design**: Fully optimized for Mobile, Tablet, and Desktop viewing experiences.
- **Internationalization (i18n)**: 
  - Supported Languages: English (`en`), Spanish (`es`), French (`fr`), Tamil (`ta`), Chinese (`zh`).
  - Seamless language switching with persistent preferences.
- **Accessibility (A11Y)**: 
  - Dynamic font size adjustment.
  - Custom cursor sizing.
  - High-contrast and system-based theme support.
- **Theming**: robust Dark, Light, and System theme toggling.

## 🛠️ Tech Stack

### Core
- **[Next.js 15](https://nextjs.org/)**: React framework for production.
- **[React 19](https://react.dev/)**: For building user interfaces.

### Styling & Animation
- **[Tailwind CSS 3](https://tailwindcss.com/)**: Utility-first CSS framework.
- **[GSAP](https://greensock.com/gsap/)**: Professional-grade animation library.

### Functionality
- **[i18next](https://www.i18next.com/)**: Internationalization framework.
- **[Nodemailer](https://nodemailer.com/)**: For handling contact form submissions.

## � Getting Started

Follow these steps to run the project locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/ManojTGN/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Run development server**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open in Browser**
   Navigate to [http://localhost:3000](http://localhost:3000) to view the application.
